# 卓上ディスプレイ（Fire HD 8 用）

使わなくなった Fire HD 8（第12世代）を、卓上の専用端末にするための Web アプリです。時計、ポモドーロタイマー、週間カレンダー、24時間の天気、定期リマインダーを表示し、SwitchBot プラグミニで充電を自動で入切できます。

- ビルド不要の静的サイト（HTML / CSS / JavaScript）。依存パッケージはありません。
- 天気は [Open-Meteo](https://open-meteo.com/)（APIキー不要・非商用）から取得します。
- 予定とプラグの操作は、自分の Google アカウントに置く中継スクリプト（`relay/Code.gs`）を通します。
- 緯度経度や中継URLは端末の画面で入力し、その端末の中にだけ保存します。SwitchBot の鍵は中継スクリプトの中にだけ置きます。**このリポジトリに秘密情報は入りません。**

設計と計画は `docs/superpowers/` にあります。実機のセットアップは [`docs/device-setup.md`](docs/device-setup.md) を見てください。

## 画面

下端のタブで切り替えます。週間・天気の画面は、2分触らないとホームに戻ります。

| 画面 | 内容 |
|---|---|
| ホーム | 時刻・日付、今の天気と雨の予告、バー式タイマー、次の予定2件、電池の残量 |
| 週間 | 今日から7日分。終日の予定、時刻付きの予定、定期リマインダーを日ごとに並べる |
| 天気 | 今の天気と、これから24時間の1時間ごとの予報（気温・降水確率） |
| タイマー | 残り時間、20目盛りのバー（残り1割で琥珀色）、完了した作業回数、開始／一時停止・リセット・スキップ |
| 設定 | 場所、カレンダー、ポモドーロの時間、明るさと夜間、充電の自動制御、定期リマインダー |

画面全体の地色がタイマーの状態を表します（待機=藍、作業=赤、休憩=緑）。夜間（既定 22:00〜7:00）は、30秒触らないと通常より暗くなります。予定・リマインダー・タイマーの通知のときは明るさが戻ります。

## 開発

```
npm test                      # ロジックと中継スクリプトの自動テスト（Node.js 22 以上）
python3 tools/e2e.py          # ブラウザでの通し確認（Playwright と Chrome が必要）
python3 tools/screenshot.py   # 5画面を out/ に PNG 出力（横置き・縦置き）
python3 -m http.server 8000   # 手元で開く → http://localhost:8000/
```

`http://localhost:8000/?demo=1` を開くと、通信せずに固定のサンプルで表示します。`file://` で直接開くと動きません（ES Modules の制約）。電池の残量は HTTPS か localhost のページでしか読めません。

## 公開

GitHub Pages など、HTTPS で静的ファイルを配信できる場所に置けば動きます。手順は `docs/device-setup.md` の「3. Webアプリの公開」にあります。

## 構成

```
src/core/      タイマー、バー、週間の振り分け、リマインダー、夜間、充電の判定、設定の検証（DOM に依存しない）
src/services/  天気・カレンダーの取得と変換、キャッシュ、再取得の間隔、プラグへの指示
src/ui/        表示用の文字列、画面の描画、通知音、減光
src/app.js     組み立てと1秒ごとの処理
relay/Code.gs  中継（Google Apps Script）: 7日分の予定、プラグの入切、連絡が途絶えたときの安全策
```
